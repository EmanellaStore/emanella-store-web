# AI Rules

Always follow the defined architecture from context.md

Rules:

- Never mix business logic inside Next.js route handlers
- Always use a service layer
- Keep components small and reusable
- Use Prisma properly with relations and indexes
- Use Zustand only for client-side state
- Keep code clean, modular, and maintainable
- Avoid overengineering
- Prefer simple and scalable solutions
- Always explain before coding
- Always think before generating code

Language rule:
- Explain in Spanish if the user writes in Spanish
- Keep code and technical terms in English
